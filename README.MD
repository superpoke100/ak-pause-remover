## Supported configurations
1. Mumu emulator 1920x1080 resolution, native recording feature
If using other recording software, ensure that UI elements of your emulator are not captured.

## Instructions
1. Place videos in the TODO folder.
2. Run process_videos.py from within the root folder.
3. Processed videos will be placed in the folder output_videos/{VIDEO_NAME}/output.mp4 once finished.
